## ✨ Возможности

Всё, что нужно. Ничего лишнего.

### 🔀 Раздельное туннелирование без боли
Список «Выбранное»: пустой — и весь трафик идёт через VPN. Добавьте домен — через VPN пойдёт только он. А «Исключения по приложениям» выпускают, например, Steam напрямую — VPN для него не нужен.

  
### 🔐 Поддерживаемые протоколы
- **VLESS + Reality**
- **VMess**
- **Trojan**
- **Shadowsocks**
- **Hysteria2**
- **TUIC**
- **WireGuard**
- **AmneziaWG**

> Ядро: `xray-core` · Подписка из 3x-ui подтягивается корректно

### 🎯 Два режима работы

| Режим | Описание | Требования |
|-------|----------|------------|
| **Системный прокси** | Включается сразу, достаточно браузеру и мессенджерам | Без прав администратора |
| **TUN-адаптер** | Заворачивает весь трафик без исключений, включая игры | Требует UAC |

### ⚡ Импорт за секунды
Вставьте `vless://`-ссылку или URL подписки — сервер появится в списке. Скопировали QR-код? M3tr0VPN распознает его прямо из буфера обмена.

### 🌍 RU / EN
Клиент двуязычный: русский и английский переключаются в один клик. Тёмно-зелёная тема (в стиле клиента Incy).

### 🔍 Прозрачность
Конфиг Xray можно открыть, посмотреть и выгрузить в JSON. Журнал ядра — перед глазами, без фильтров. Никаких скрытых телеметрий и «отстуков на левые сервера».
